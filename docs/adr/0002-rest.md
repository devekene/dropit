# ADR-0002: REST/JSON and modular monolith
Status: Accepted

Context: Small stable resource domain and a 3–5 day MVP goal.
Decision: NestJS/Fastify REST/JSON, OpenAPI, PostgreSQL, S3; no GraphQL, WebSockets, Redis or message broker initially.
Consequences: Simple observability and deployment; future live peer transfer requires a separate ADR and signaling design.
